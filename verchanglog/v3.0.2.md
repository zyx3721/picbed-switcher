## 📋 版本概述

v3.0.2 围绕二进制部署体验与发布工程化能力升级。后端新增命令行参数与版本信息支持，部署时可通过 `-v` 查看版本、通过参数覆盖服务器与数据库配置；Release 产物从 Linux 双架构扩展至 Linux/macOS/Windows 六平台，并统一为单个 `SHA256SUMS` 校验文件；新增 `scripts/` 运维脚本目录，提供后端服务启停管理与二进制部署在线更新能力；文档体系同步重整为中文主 README、English 版与 `docs/manual.md` 完整手册三层结构。

---

## ✨ 新增特性

- 后端支持命令行参数：`-v`/`-version` 显示版本信息（版本、commit、构建时间、Go 版本），`-env` 指定 `.env` 配置文件路径，`-host`/`-port`/`-mode`/`-db-*`/`-jwt-secret` 与环境变量一一对应，显式传入的参数优先于环境变量与 `.env` 文件。
- 后端 `-h` 自定义帮助输出，参数描述统一对齐；启动日志带版本号输出。
- 新增 `internal/buildinfo` 版本信息包，发布构建通过 `-ldflags -X` 注入版本号、commit 与构建时间，源码直接编译时默认显示 `dev`。
- Release 产物新增 macOS（AMD64/ARM64）与 Windows（AMD64/ARM64）压缩包，平台覆盖扩展至 Linux、macOS、Windows 六平台。
- Docker 镜像新增 ARM64 架构支持，镜像发布覆盖 `linux/amd64` 与 `linux/arm64` 双平台。
- Docker 镜像新增阿里云镜像仓库推送，与 Docker Hub 同步发布。
- 新增 `scripts/run.sh` 后端服务启停管理脚本，支持 `start`/`stop`/`restart`，基于 PID 文件守护进程，停止时先优雅退出再强制终止。
- 新增 `scripts/update-picbed-switcher.sh` 二进制部署在线更新脚本：分页抓取 GitHub 全部 Release、交互选择版本、下载并基于 `SHA256SUMS` 校验完整性、原子替换后端二进制与前端静态目录，新版本启动异常时自动回滚旧版本。
- 构建支持参数化配置依赖源：Dockerfile 支持 `NPM_REGISTRY` 与 `GOPROXY` 构建参数，适配不同网络环境。

## 🔧 重构优化

- 发布产物校验和统一为单个 `SHA256SUMS` 文件，汇总后端与前端全部压缩包，文件名去除目录前缀，可直接执行 `sha256sum -c SHA256SUMS` 校验。
- 配置加载拆分出 `LoadWithOverrides`，取值优先级为命令行参数 > 环境变量（含 `.env`）> 默认值，原 `Load` 保持兼容。
- Docker 构建禁用 provenance，镜像标签更精简；后端 Docker 构建补收 `APP_VERSION`/`APP_COMMIT`/`APP_BUILD_DATE` 构建参数并注入版本信息。
- 删除后端全部单元测试文件，验证方式以 `go vet` 与实际运行为准。
- 文档体系重整：原 `README.md` 迁移为 `docs/manual.md` 完整手册，新增精简中文主 `README.md` 与英文 `README.en.md`，形成「主文档概览 + 完整手册」三层文档结构。

## 🔄 升级说明

从 v3.0.1 升级到 v3.0.2 无需执行数据库迁移。

**二进制部署升级**：

- 使用 `scripts/update-picbed-switcher.sh` 可在线完成更新；或按 README 手动下载六平台产物，校验命令调整为 `sha256sum -c SHA256SUMS`（原按版本命名的 checksums 文件已移除）。
- 升级后可执行 `./picbed-switcher -v` 确认版本，`./picbed-switcher -h` 查看命令行参数；服务器、数据库与 JWT 配置可通过参数临时覆盖，优先级高于环境变量与 `.env` 文件。

**Docker 部署升级**：

- 拉取新镜像后按原命令重新创建容器即可；ARM64 机器（如鲲鹏、飞腾、Apple Silicon）可直接拉取对应架构镜像。
- 镜像内后端已注入版本信息，可通过容器日志观察启动版本号。

**macOS / Windows 用户**：

- 本版本起新增 `picbed-switcher_<版本>_darwin_*.tar.gz` 与 `picbed-switcher_<版本>_windows_*.zip` 产物；Windows 包内可执行文件为 `picbed-switcher.exe`。
